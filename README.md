## Запуск проекта
1. Получить ключ на сайте https://kinopoiskapiunofficial.tech/ и добавить в .env файл.
2.  Получить ключ на сайте https://rapidapi.com/hub и добавить в .env файл.
3. npm install
4. npm run dev

## Технологии
1. TypeScript
2. React
3. Redux Toolkit + query
4. MUI
